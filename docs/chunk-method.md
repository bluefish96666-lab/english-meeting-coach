# 语块训练法对照（来源剪藏）

来源：[别再让 ChatGPT 陪你尬聊了：这样用语音模式，把英语语块练成条件反射](https://x.com/momoai_daily/article/2094725921013964938)（momoai沫沫，2026-09-01）

## 核心主张

- 开口 ≠ 训练。要有目标表达、主动提取、纠错回收、间隔复习。
- 训练单位是 **lexical chunks（语块）**，不是散单词，也不是整篇背诵。
- 闭环：`听见 → 注意 → 模仿 → 连接现实 → 主动提取 → 纠错重说 → 间隔回收`
- 纠错用 **recast**：给更自然版本 → 立刻重说；不要每句打断上语法课。
- 每次只练 **3–5 个**可迁移语块。

## 文章流程 → 本应用入口

| 文章方法 | 应用入口 |
| --- | --- |
| 15 分钟语块口语教练（10 阶段） | 欢迎页「语块教练 · 15 分钟」 |
| 跟读 / 声音模仿 | 「跟读 · 会议节奏」 |
| 主动提取 / 盲测 | 「语块反射 · 3 秒」+ 表达库盲测 |
| 半句暂停预测 | 「半句暂停」 |
| 先流畅，再纠最值当的问题 | 设置「先流畅后纠错」+ 纠错卡「重说」 |
| 自由聊后反推缺失语块 | 「结束复盘」后的「诊断提炼」 |
| 间隔回收 | 今日训练闭环 + 语块掌握状态（主动/需提示/仍需复习） |

## 刻意不做

- 不做音素级发音打分（文章也强调 AI 不宜假装精确声学判断）
- 不堆生僻俚语；会议语块优先高频可迁移
- 不从中文翻译题起步；场景/画面触发优先
