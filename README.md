# Dave · 英文会议陪练

纯前端静态页：用 AI 陪你练**会议英语语块**，而不是尬聊天气。

> 中文界面，练习内容是英文。API Key / 历史 / 语块库只存在本机 `localStorage`。

训练法对齐剪藏：[别再让 ChatGPT 陪你尬聊了…](docs/chunk-method.md) ——  
**听见 → 注意 → 模仿 → 连接现实 → 主动提取 → 纠错重说 → 间隔回收**。

## 今日闭环（欢迎页）

1. **跟读 · 会议节奏** — 8–12 词口语句，TTS → 跟读 → 词重叠反馈  
2. **语块反射 · 3 秒** — 中文场景 → 限时调取语块骨架  
3. **半句暂停** — 听前半句，补出后半搭配（预测误差记忆）  
4. **语块教练 · 15 分钟** — 一次只练 **3** 个可迁移语块（10 阶段教练流程）  
5. **对练 5 轮** — 多角色会议情景（Dave / 面试官 / 客户 / 雅思 / 旅行）  
6. **复盘诊断** — 文字复盘 + 一键提炼「最缺的 3 个语块」

## 关键能力

- **Recast 重说**：纠错卡提供「听自然版 / 立刻重说 / 收进语块库」——先给自然版，再逼你重说，而不是讲语法课  
- **先流畅后纠错**（设置）：对练中不弹纠错卡，复盘时一次性汇总并挑最该改的 3 处  
- **严格纠错**（设置）：红线 + 错误标签  
- **3 秒开口**（设置）：对方说完倒计时，打破完美主义  
- **行业行话**：IT / 产品 / 商务包，注入对练用词  
- **语块库掌握度**：仍需复习 / 需提示 / 主动调用（本机标记）  
- 流式输出、免提语音、历史恢复、手机抽屉

## 运行

语音识别需要 `localhost` 或 `HTTPS`：

```bash
cd english-meeting-coach
python -m http.server 8000
# http://localhost:8000
```
