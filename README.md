# Dave · 英文会议陪练

一个纯前端静态网页，让一个会打断、会追问、会纠错的 AI「产品经理 Dave」陪你练英文会议口语。

> 全程中文界面，练习内容是英文。数据（API 设置 / 历史会话 / 表达收藏）只存在你本机浏览器 `localStorage`，不上传任何服务器。

## 功能

- 🎭 **多角色扮演陪练**：产品经理 Dave（语速快、爱打断、追问 why / what if）、英文面试官、商务客户、雅思口语考官、旅行实景（机场/海关/餐厅/酒店），顶部下拉一键切换。
- 🗂 **每个角色独立场景**：Dave 的 5 个会议场景 / 面试官 5 类问题 / 客户 5 类商务沟通 / 雅思 Part 1–3 / 旅行 5 场景（值机、海关、航班询问、餐厅点餐、酒店入住）。
- 📝 **逐轮中文纠错**：每轮跳出角色，按 `① 你说的是 / ② 更地道的是 / ③ 为什么` 三行格式纠错，并按当前角色的 `focusDims` 点出本轮最该练的一个点。
- 🔴 **严格纠错模式**（设置里默认关）：开启后逐条挑语法/用词问题，纠错卡红线标出原文，并显示错误标签芯片。
- ⏱ **3 秒开口挑战**（设置里默认关）：对方朗读结束后倒计时 3 秒；开始打字或开麦即过关。超时只提示「先说 Yes / I think...」，不会空发。
- 🗂 **会议语块 + 行业行话**：侧栏「语块」页提供 10 个万能语块（求助/观点/建议/经验/反驳/对齐/延期/澄清/承诺/推回），每张卡带中文、例句、变形句，可填入、跟读或收藏进表达库；设置里选 IT / 产品 / 商务 加载行话，并注入对练用词。
- 🎧 **跟读 · 会议节奏**：欢迎页入口。每句 8–12 词口语句，听 TTS 示范 → 开麦跟读 → 按词重叠给「跟上了 / 漏了哪些词」反馈（比节奏与用词，**不是**发音打分）。
- ⚡ **语块反射 · 3 秒**：欢迎页入口。看中文场景提示 → 3 秒内说出对应英文语块（答案先模糊，说完或点「看答案」才揭示）。只对语块骨架计分，练的是「不经思考就调取」；一组 10 题结束给命中率和判断。
- 🧘 **先流畅后纠错**（设置里默认关）：对练中不弹纠错卡，避免边说边被打断；点「结束复盘」时一次性汇总所有逐轮纠错，并让 AI 挑出最该改的 3 个错误。
- 📅 **今日训练**：欢迎页显示四步闭环（跟读 1 组 → 语块反射 1 组 → 对练 5 轮 → 结束复盘）的完成状态和连续天数，数据只存本机。
- 🎤 **语音输入 / 输出**：用麦克风说英文（Web Speech API），AI 回复自动朗读。
- ⌨️ **流式输出**：默认开启。对方的 `reply` 以打字机方式边生成边显示，结束后再解析 JSON 纠错；模型不支持或流出错时自动回退到一次性请求。
- 🎧 **免提模式**：默认关闭。开启后：对方朗读结束 → 自动听你说 → 识别完自动发送 → 再流式回复并朗读。没听清会重试一次，仍无内容则暂停监听（避免空转）。
- ⭐ **表达收藏**：纠错里的地道表达一键收藏；侧栏可单条朗读或点「朗读全部」串行复习。
- 🕘 **历史会话**：练习记录保存在本机。点历史卡片会恢复当时的完整对话（过长会截断到最近若干条）；「新会话」仍只开空场景。
- 🔌 **通用模型**：兼容 OpenAI 接口格式，DeepSeek / OpenAI / Moonshot / xAI Grok / 智谱 GLM / 通义 Qwen 可一键预置，Key 自己在页面填。
- 📱 **手机端**：窄屏时侧栏收起，底部「句型 / 收藏 / 历史」可打开抽屉。

## 运行

这是纯静态页面，但**语音识别要求 `localhost` 或 `HTTPS`**，所以不要双击 `file://` 直接开。任选一种：

```bash
# 方式一：Python（推荐，最简单）
cd english-meeting-coach
python -m http.server 8000
# 浏览器打开 http://localhost:8000

# 方式二：Node
npx serve .
# 浏览器打开 http://localhost:3000
```

## 配置模型

打开页面右上角「⚙ 设置」，选一个预设或手动填：

| 服务 | Base URL | 模型名 |
| --- | --- | --- |
| DeepSeek（默认） | `https://api.deepseek.com/v1` | `deepseek-chat` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| Moonshot | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| xAI Grok | `https://api.x.ai/v1` | `grok-4.6` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| 通义 Qwen | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |

- **API Key**：填你自己的 Key，只存本机浏览器。
- **强制 JSON 输出**：默认开启（DeepSeek/OpenAI 支持）。若某个模型报错或返回格式混乱，关掉它，程序会自动兜底解析。
- **流式输出**：默认开启。关掉则恢复一次性请求。流式失败（不支持 SSE 等）会自动回退，不必手关。
- **免提模式**：默认关闭。保存开启后：若正在朗读，会等这次朗读结束（`onend`）再开麦；当前没有朗读才立即开始听。点 🎤 开始录音时才会取消 TTS。点 🎤 可随时打断。
- **严格纠错**：默认关闭。开启后纠错更狠，红线标出问题，并显示错误标签。
- **3 秒开口挑战**：默认关闭。对方说完开始倒计时，逼自己先开口。
- **先流畅后纠错**：默认关闭。开启后对练中不显示纠错卡，结束复盘时统一汇总。
- **行业行话包**：选 IT / 产品 / 商务后，侧栏显示对应行话，并对练提示词会带上相关用词（不强迫每句都用）。
- **测试连接**只用当前表单里的临时配置，**不会写入设置**。看到「连接成功，记得点保存」后再点「保存」才生效。
- 常见错误会映射成中文：401 Key 无效、404 模型名/Base URL 不对、429 限流。

## 使用流程

1. 顶部选角色（产品经理 / 面试官 / 客户 / 雅思考官 / 旅行），再选场景（或直接点欢迎列表里的数字）。旅行角色会按场景切换成地勤、海关官、航司柜台、餐厅服务员或酒店前台。
2. 按欢迎页「今日训练」走：先「跟读 · 会议节奏」热身，再「语块反射 · 3 秒」把语块练成反射；对练时可从侧栏「语块」填入。
3. 对方说英文开场白 → 你打字或点 🎤 说话回应。若开了 3 秒挑战，朗读结束后会倒计时。若开了免提，开场白读完会自动听你说。
4. Dave 在角色里用英文追问/打断 → 然后跳出角色给出中文纠错（严格模式会红线标错）。
5. 觉得某句「更地道的」有用，点 ☆ 收藏；会后可在「表达收藏」里朗读或点「朗读全部」。
6. 练得差不多了，点右上角「结束复盘」，让 AI 给出今日复盘 + 明天重点 + 最该补的一个表达。
7. 以后想回看：打开「历史」，点卡片即可恢复当时对话。

## 浏览器要求

- 语音识别/合成用 Web Speech API：**Chrome / Edge** 效果最好；Safari 语音输入支持有限。
- 必须通过 `localhost` 或 `HTTPS` 访问，麦克风才会被允许。
- 跟读反馈基于识别文本与原文的词重叠，**不做**音素/波形发音评分。

## 文件结构

```
english-meeting-coach/
├── index.html    # 页面结构
├── styles.css    # 样式
├── content.js    # 会议语块（模板/例句/变形/反射提示）/ 行业行话 / 跟读句子
├── app.js        # 全部逻辑（提示词、LLM 调用、语音、存储）
└── README.md
```

想改角色的人设、语气或场景，打开 `app.js`，改顶部的 `PERSONAS`（每个角色含 `promptBody` 人设规则 + `scenarios` 场景/开场白 + `focusDims` 纠错侧重）即可；`buildSystemPrompt()` 负责把角色、行业行话和纠错格式拼在一起。句型与行话内容在 `content.js`。
